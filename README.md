# Reality Stage

A browser-first local web app where webcam gestures control a cinematic Three.js stage with Rapier physics, MediaPipe hand tracking, Theatre.js camera rigging, Hydra visuals, Rive animation, Lenis scroll chapters, and AutoAnimate UI transitions.

## Local Development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

## GitHub Pages

This repo is configured for GitHub Pages from the `main` branch `/docs` folder. For a repository named `reality-stage`, the public URL will be:

```text
https://<github-username>.github.io/reality-stage/
```
